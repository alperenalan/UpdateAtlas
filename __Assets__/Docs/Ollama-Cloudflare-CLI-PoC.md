# Ollama and Cloudflare CLI proof

On this Mac on 2026-10-30, `Apple/Proofs/OllamaCLI/probe.py` observed `/usr/local/bin/ollama` resolving to `/Applications/Ollama.app/Contents/Resources/ollama`, whose app bundle reports `com.electron.ollama` and version `0.40.11`. Update Atlas already has the Ollama app catalog rule `ollama-macos-stable`; the CLI is now a child of that app when the exact link and bundle are present. It reads the same app version from the bundle's `Info.plist`. The CLI has no separate update action; Ollama's own app updater owns installation. A standalone `ollama` binary that is not linked to a discovered app remains its own row with no invented version or update ownership. Ollama's [macOS installation guide](https://docs.ollama.com/macos) describes the app-owned CLI link, and the [updater source](https://github.com/ollama/ollama/blob/main/app/updater/updater.go) shows the app update process.

`Apple/Proofs/CloudflareCLI/probe.py` observed the global npm package `cf` at `~/.local/lib/node_modules/cf`, with both `cf` and `cloudflare` links pointing to its installed command, version `1.0.0-beta.12`. Update Atlas's existing npm scanner already identifies that package by its stable npm package name, reports the installed version, and uses npm's global `outdated` result for update status. Its visible name is now **Cloudflare CLI (cf)**, without changing its package identity or creating a second standalone row. The package manager owns updates; Update Atlas does not run a global npm installation. Cloudflare's [installation guide](https://developers.cloudflare.com/cf/get-started/) documents `npm install --global cf@latest` for an explicit update. Since `cf` is a beta, the npm `latest` tag and the installed prerelease need comparison; an older tag is not shown as an update.

Both probes are read-only and returned `updateStatus: notChecked`; neither ran an update. The app catalog's release source and npm's online status were not queried by these probes. Discovery and classification regressions cover the exact app link, standalone and manager-owned cases, and the unchanged npm identity. Test execution evidence is recorded on the Jira delivery card.
