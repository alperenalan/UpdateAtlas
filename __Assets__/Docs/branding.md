# Application icon

Update Atlas uses a single dark navy icon with a blue segmented package mark. The package represents the complete software inventory; separated top panels suggest multiple update sources being resolved into one coherent view.

The high-resolution transparent source is stored locally at `__Assets__/Design/AppIcons/UpdateAtlas.png`. Its bytes are identical to the tracked `Apple/UpdateAtlas/Assets.xcassets/AppIcon.appiconset/icon_1024x1024.png`; Xcode consumes the generated 16–1024 px representations in that asset catalog for Finder, Dock, and application metadata.

## Optional support link

The sidebar uses a compact native support link, and the one-time reminder uses an SF Symbol. Both open Alperen's supplied Buy Me a Coffee page. The third-party Buy Me a Coffee button graphic was removed from the repository before relicensing.
