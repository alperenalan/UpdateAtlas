您 Mac 上的每个应用，每次更新都为您检查。

Update Atlas 会找到您的应用、游戏和命令行工具，并告诉您哪些更新真实可靠、应在哪里安装。

首个公开版本即将推出。

免费开源。需要搭载 Apple 芯片并运行 macOS 14 或更高版本的 Mac。

一切尽在一份清晰的列表中。

一眼看清 Mac 上安装了什么，以及每个软件的更新由谁负责。

  • 您的所有软件

    应用，Steam、GOG 和 Epic 游戏，Homebrew、npm 和 Python 软件包，以及命令行工具，一并列出。

  • 依据证据，而非猜测

    只有经过可靠的版本检查，应用才会被标记为最新。未能核实的项目会清楚标注。

  • 用正确的方式更新

    查看每个更新由谁负责：App Store、Sparkle、Homebrew 或开发者。受支持的更新只会在您确认后开始。

  • 常驻菜单栏

    在菜单栏中低调显示更新数量，并在确认有新更新时发送通知。

  • 应用及其组件

    扩展、插件和辅助工具会归入管理它们的应用之下。

  • 隐私为先

    无需账户，没有分析，没有广告。Update Atlas 从不上传您的软件列表。

即使关闭窗口，也触手可及。

Update Atlas 可以在菜单栏中持续运行，按您选择的频率检查更新，并一键打开任意更新。

在终端中同样得心应手。

内置的命令行工具以 JSON 格式输出同样的清单，可直接用于脚本和 AI 助手。

$ update-atlas check --updates-only
$ update-atlas scan --offline | jq '.summary'
$ update-atlas skill > SKILL.md

常见问题

Update Atlas 真的免费吗？

是的。没有广告、账户或付费版本。支持完全自愿，不会解锁任何功能。

它会自动更新我的应用吗？

不会。扫描只读取信息。只有在您选择并确认后，且其更新负责方能够安全安装时，更新才会开始。

哪些数据会离开我的 Mac？

您的软件列表会保留在 Mac 上。为了检查版本，Update Atlas 会连接您的应用的官方更新来源，并从本网站下载公开的软件目录。

它能在 Intel Mac 上运行吗？

Update Atlas 本身需要搭载 Apple 芯片并运行 macOS 14 或更高版本的 Mac，但仍会列出这台 Mac 上安装的 Intel 应用。

某个应用缺失或显示有误，我该如何帮忙？

请在 GitHub 上提交 issue，注明应用名称和下载来源。软件目录独立于应用进行更新。
