隐私

最后更新：2026年10月24日

Update Atlas 旨在让您的信息留在 Mac 上。本页说明该应用会读取什么、会连接哪些服务，以及绝不会收集什么。

保留在 Mac 上的内容

为了生成列表，Update Atlas 会读取应用信息、软件包管理器记录以及您选择的文件夹。列表、设置、更新历史和目录缓存只存储在您的 Mac 上。

应用会连接的服务

为了检查版本，Update Atlas 会连接您的软件的更新来源，例如开发者的更新源、App Store、GitHub 和软件包仓库。这些服务会收到一次普通的网络请求（包括您的 IP 地址），并按其各自的隐私政策处理。

目录与应用更新

Update Atlas 会在启动时以及每六小时从本网站下载公开的软件目录；在开启更新检查或您手动检查时，也会在本网站查询 Update Atlas 的新版本。这些请求不包含任何关于您的软件的信息。

绝不收集的内容

没有账户、分析、广告或跟踪。Update Atlas 从不上传您的软件列表，未经您确认也绝不会安装任何内容。

本网站

本网站不使用 Cookie、分析工具或第三方脚本。您选择的语言和主题只保存在您的浏览器中。我们的托管服务商 Cloudflare 会处理标准的请求日志。Buy Me a Coffee 和 GitHub Sponsors 是独立的服务，适用其各自的条款。
