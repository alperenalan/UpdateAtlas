Update Atlas は、あなたの情報を Mac の中にとどめるよう設計されています。このページでは、アプリが読み取るもの、接続する先、そして決して収集しないものを説明します。

Mac に残るもの

一覧を作成するために、Update Atlas はアプリの情報、パッケージマネージャーの記録、あなたが選んだフォルダを読み取ります。一覧、設定、アップデート履歴、カタログのキャッシュは Mac にのみ保存されます。

アプリが接続する先

バージョンを確認するため、Update Atlas は開発元のアップデートフィード、App Store、GitHub、パッケージレジストリなど、ソフトウェアのアップデート提供元に接続します。これらのサービスは IP アドレスを含む通常の Web リクエストを受け取り、それぞれのプライバシーポリシーに従って扱います。

カタログとアプリのアップデート

Update Atlas は起動時と6時間ごとに、このサイトから公開ソフトウェアカタログをダウンロードします。また、アップデートの確認がオンのとき、または手動で確認したときに、新しい Update Atlas があるかをこのサイトで確認します。これらのリクエストにお使いのソフトウェアに関する情報は含まれません。

決して収集しないもの

アカウント、解析、広告、トラッキングは一切ありません。Update Atlas がソフトウェアの一覧をアップロードすることはなく、あなたの確認なしに何かをインストールすることもありません。

このサイト

このサイトは Cookie、解析、サードパーティのスクリプトを使用しません。言語とテーマの選択はブラウザにのみ保存されます。ホスティング事業者の Cloudflare は標準的なリクエストログを処理します。Buy Me a Coffee と GitHub Sponsors は、それぞれ独自の規約を持つ別のサービスです。
