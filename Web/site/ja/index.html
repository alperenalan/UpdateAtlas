Mac のすべてのアプリ。すべてのアップデートを確認。

Update Atlas はアプリ、ゲーム、コマンドラインツールを見つけ出し、本物のアップデートと、それをどこからインストールすればよいかを示します。

最初の公開リリースはまもなくです。

無料かつオープンソースです。Apple シリコン搭載で macOS 14 以降の Mac が必要です。

すべてを、わかりやすいひとつのリストに。

Mac に何がインストールされていて、それぞれのアップデートを誰が管理しているかがひと目でわかります。

  • すべてのソフトウェア

    アプリ、Steam・GOG・Epic のゲーム、Homebrew・npm・Python のパッケージ、コマンドラインツールを並べて表示します。

  • 推測ではなく、根拠を

    信頼できるバージョン確認を経て初めて「最新」と表示されます。確認できなかった項目ははっきり区別されます。

  • 正しい方法でアップデート

    App Store、Sparkle、Homebrew、開発元など、各アップデートの管理元がわかります。対応するアップデートは、確認後にのみ開始されます。

  • メニューバーに常駐

    メニューバーにアップデート件数を控えめに表示し、新しいアップデートが確認されると通知します。

  • アプリとその中身

    拡張機能、プラグイン、補助ツールは、それらを管理するアプリの下にまとめて表示されます。

  • プライバシーを第一に

    アカウント不要、解析なし、広告なし。Update Atlas がソフトウェアの一覧をアップロードすることはありません。

ウインドウを閉じても、すぐそばに。

Update Atlas はメニューバーで動作し続け、選んだ間隔でアップデートを確認し、ワンクリックで任意のアップデートを開けます。

ターミナルでも使いやすく。

付属のコマンドラインツールは同じ一覧を JSON で出力するので、スクリプトや AI アシスタントですぐに使えます。

$ update-atlas check --updates-only
$ update-atlas scan --offline | jq '.summary'
$ update-atlas skill > SKILL.md

無料、そしてオープンソース。

Update Atlas はひとりの開発者が作り、GPL-3.0 ライセンスで公開しています。時間の節約に役立ったら、開発を支援していただけるとうれしいです。

よくある質問

Update Atlas は本当に無料ですか？

はい。広告、アカウント、有料プランはありません。支援は任意で、それによって機能が解放されることもありません。

アプリを自動的にアップデートしますか？

いいえ。スキャンは情報を読み取るだけです。アップデートは、あなたが選んで確認し、かつ管理元が安全にインストールできる場合にのみ開始されます。

Mac からどんなデータが送信されますか？

ソフトウェアの一覧は Mac に残ります。バージョン確認のため、Update Atlas はアプリの公式アップデート提供元に接続し、公開されているソフトウェアカタログをこのサイトからダウンロードします。

Intel 搭載の Mac で動きますか？

Update Atlas 自体には、Apple シリコン搭載で macOS 14 以降の Mac が必要です。その Mac にインストールされている Intel 用アプリも一覧に表示されます。

アプリが見つからない、または表示が正しくない場合は？

アプリ名と入手先を添えて GitHub で issue を作成してください。ソフトウェアカタログはアプリとは別に更新されます。
